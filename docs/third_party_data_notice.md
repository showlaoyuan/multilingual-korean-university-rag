# Third-Party Data Notice

This project was developed with publicly accessible administrative documents from the official websites of five Korean universities:

- [Hankuk University of Foreign Studies Graduate School](https://gra.hufs.ac.kr/)
- [Yonsei University Graduate School](https://graduate.yonsei.ac.kr/)
- [Hanyang University Academic Information](https://academic.hanyang.ac.kr/)
- [Ewha Womans University Graduate School](https://graduate.ewha.ac.kr/)
- [Sogang University Graduate School](https://gradsch.sogang.ac.kr/)

The local research corpus contains PDF, HTML, and HWPX materials covering academic requirements, examinations, thesis procedures, course registration, leave and return procedures, scholarships, and international-student administration. The source set used for the frozen experiments was checked on 2026-10-02. University policies can change, and the archived versions must not be treated as current administrative advice.

The repository's AGPL-3.0-only license applies only to original project code covered by the project [`NOTICE`](../NOTICE); it does not grant rights in university documents or their reconstructable derived text.

Source documents, reconstructable extracted text, full chunks, and derived vector indexes are not included in the public release boundary. This reduces the risk of redistributing third-party material outside its original context and avoids presenting archived policies as current official guidance.

Anyone reproducing the project should obtain the current documents directly from the relevant official university website, review the site's terms and document notices, and verify the applicable university, campus, degree level, department, student status, and effective date before using the information.
